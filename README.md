# 민사소송법 문구 연습

책의 키워드와 정확한 문구를 **직접 쓰는** 개인 학습용 정적 웹앱입니다. 로그인·유료 AI·외부 API·Node 설치가 필요 없습니다.

## 실행

1. 이 폴더의 `start-local.cmd`를 더블클릭합니다. Python 3가 설치되어 있으면 기본 브라우저도 엽니다. 같은 앱이 이미 켜져 있으면 중복 실행하지 않습니다.
2. 브라우저에서 **http://127.0.0.1:4194/** 를 엽니다.
3. 서버 종료는 실행 창에서 **Ctrl+C**. 브라우저만 닫는 것은 서버 종료가 아닙니다.

터미널에서 직접 실행하려면 이 폴더에서:

```powershell
py -3 serve.py
```

포트가 이미 사용 중이면 기존 미리보기를 이용하거나 다른 포트를 지정하세요. 무관한 서버를 종료하지 않습니다.

```powershell
py -3 serve.py --port 4196
```

이 경우 http://127.0.0.1:4196/ 를 엽니다. **주소·포트·브라우저가 바뀌면 저장공간도 달라집니다.** 기존 기록은 내보내기·가져오기로 옮기세요. 인터넷에 공개된 서버가 아니라 현재 컴퓨터에서만 접근하는 주소입니다.

## 공부 순서

- 진도와 원문 번호를 고르고 ① 핵심어 → ② 핵심어 확장 → ③ 목록 → ④ 문장 → ⑤ 전체 답안 순서로 직접 입력합니다. 이미 아는 단계는 건너뛰세요.
- 빈칸은 **토씨를 제외한 선정 핵심 단어**입니다. 위치 바꾸기로 가리는 단어를 바꿉니다. ②도 마지막 요청에 맞춰 긴 문구 전체가 아닌 핵심 단어를 가립니다.
- 문장·전체 답안은 **각 문장 안의 선정 핵심어 배열 순서**로 채점합니다. 목록 항목의 순서는 자유롭습니다. 항목마다 줄바꿈하면 대응이 정확해집니다.
- 조문·숫자, 각하/기각, 일부 부정·효과 역전은 별도 검사합니다. 등록되지 않은 동의어는 자동 허용하지 않습니다. 허용 표현은 기록·도움말에 있습니다.
- 채점 뒤 기준 답안과 대조하고 기억 상태를 기록합니다. `틀린 부분 다시 쓰기`는 누락 핵심 단어만, `이 부분 전체 다시 쓰기`는 문장 전체를 연습합니다. 재입력 답안도 저장됩니다.
- 원문·힌트·정답 열람과 즉시 교정 풀이에는 도움 표시가 남습니다. 새 풀이에서도 열람 후 최소 10분 **및 다른 3문항**을 기록하기 전에는 독립 성공으로 세지 않습니다.
- `오늘 복습`, `취약 문구`, `새 문제`, `전 범위 점검`을 사용하세요. 오답은 다른 3문항 뒤 재출제됩니다. 독립 성공은 서로 다른 날짜로 집계하며 1·3·7·14·30일 간격으로 복습합니다. 단일 성공을 암기 완료로 표시하지 않습니다.
- 입력은 자동 저장됩니다. `새 풀이`는 이전 답안을 덮어쓰지 않습니다. `이어 풀기`는 최근 작성 답안으로 돌아갑니다. 다른 장치에는 JSON 기록을 옮기세요. 같은 주소를 여러 창에서 동시에 작성하지 마세요.

## 수록 범위와 정확성

- 「주관식 핵심민사소송법의맥_1.pdf」 **PDF 1–10쪽 / 책 150–159쪽 / 원문 1–44번 전부**.
- 11번은 PDF 2→3쪽, 32번은 7→8쪽 연결. 14·22번 표 각각 3행을 수록했습니다.
- OCR 후 10쪽 이미지를 읽으며 수동 전사·대조했습니다. 원문 문제·답안·참조·두문자·표는 `data/source.js`에 보존합니다. 줄바꿈과 행 끝 띄어쓰기는 정리했습니다. 사람이 전사한 자료이므로 오타 가능성을 완전히 배제하지 않습니다. `원문 확인`에서 스캔을 직접 대조할 수 있습니다.
- 공식 근거로 확인한 3·26·33·42번의 교정·보충은 `data/corrections.js`로 분리합니다. 원문은 바꾸지 않습니다. 33번의 종전 판례 설명은 원문에 남기되 현재 법리 암기 답안에서 제외합니다.
- **42번 ③ 증거 범위의 일반화는 확인 보류**이며 자동 암기 출제에서 제외합니다. 8·13번에는 주의 메모가 있습니다. 모든 조문·법리가 최신 기준으로 전수 검증된 것은 아닙니다. 공식 근거 링크와 확인 범위는 원문 화면에 표시합니다.
- 진도·선정어·추가 비교 8개는 `data/learning.js`의 **학습용 가공**이며 원문 문항과 구별합니다. 추가 비교에는 근거 문항을 연결했습니다.

## 자동 채점의 한계

두 점수는 `필수 핵심어 포함`과 `핵심어 순서 재현`입니다. **법적 정확성·시험 점수 확정 판정이 아닙니다.** 요청에 따라 핵심어 나열도 어순 연습 성적으로 인정하지만, 주체·조건·복잡한 예외·문장 전체 의미는 직접 대조해야 합니다. 같은 단어를 여러 요건에 중복 대응한 답안은 완전 정답으로 인정하지 않습니다. 부정 문맥 자동 탐지도 제한적입니다.

`44문항 진도`의 부분 수는 해당 부분을 **연습한 기록**이지 그 문항 전체 암기 완료가 아닙니다. 독립 성공 날짜도 해당 단계·부분의 기록입니다.

## GitHub Pages와 저작권

**전사된 책 내용도 저작권 대상입니다. PDF만 뺀다고 공개 재배포가 자유로운 것은 아닙니다.** 권리자 허락 없이 책 내용 전체를 공개 저장소·공개 Pages에 올리지 마세요. 허락을 받거나 자기 저작 자료로 교체한 경우 아래 배포 파일을 올리면 됩니다. 개인용 로컬 사용은 현재 폴더 구성 그대로 가능합니다.

필수 정적 배포 파일:

```text
index.html
styles.css
.nojekyll
data/source.js
data/corrections.js
data/learning.js
js/core.js
js/app.js
```

`private-sources/`의 PDF·PNG와 `work/`, `test-results/`는 **공개 업로드하지 마세요**. `.gitignore`도 함께 올려 자동 제외하세요. GitHub 웹 업로드는 `.gitignore`를 무시하고 선택 파일을 올릴 수 있으므로 직접 제외해야 합니다. `serve.py`, `start-local.cmd`, 테스트 파일은 Pages 실행에 필요 없습니다. README는 올려도 됩니다.

GitHub에서 저장소 생성 → Add file → Upload files → 위 파일의 **폴더 구조를 유지**해 업로드 → Settings → Pages → Deploy from a branch → main / (root) → Save. API·서버 없이 실행됩니다. 배포판에는 개인 원문 이미지가 없고, 원문 확인에서 `내 PDF 선택`으로 현재 장치의 PDF를 열 수 있습니다. 선택한 PDF는 서버에 업로드되지 않으며 새로고침하면 다시 선택해야 합니다.

## 유지보수·검사

- 원문: `data/source.js`
- 확인된 교정과 보류: `data/corrections.js`
- 학습용 선정어·허용 표현·진도·추가 비교: `data/learning.js`
- 빈칸 범위는 선정어의 정확한 문자열 위치로 생성하며 법적 핵심이 아닌 조사만 가리는 방식이 아닙니다.
- 채점·복습: `js/core.js` / 화면·자동 저장: `js/app.js`
- 학습기록은 브라우저 localStorage에만 보관되며 내보내기 JSON이 백업입니다.

개발용 검사는 Node가 있을 때 `node --test tests/core.test.cjs`. 브라우저 검사는 로컬 서버에서 `/tests/browser.html`을 열고 검사 시작. 테스트는 `?test=1` 전용 저장공간을 사용합니다. 일반 학습기록을 덮어쓰지 않습니다.

검사 범위와 한계는 `VERIFICATION.md`에 적었습니다.
